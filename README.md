# Love and Information - Interactive Theater System

An innovative technological system for a theatrical production that explores the evolution of the internet through Caryl Churchill's "Love and Information". This system collects audience data through interactive forms and utilizes algorithms to dynamically determine scene ordering and actor assignments, creating a unique, audience-influenced performance each time.

## Features

- 📊 Real-time audience data collection through interactive forms
- 🎭 Dynamic scene ordering based on audience input
- 🎲 Automated scene assignment system for the 26th actor
- 🎨 Interactive performance customization
- 📱 Mobile-friendly interface
