# Love and Information - Interactive Theater System

Caryl Churchill's Love and Information (2012) presents a unique theatrical challenge. The play consists of seven sections containing over 60 short scenes, which are intended to be performed in different arrangements each night.
For Queen's University's production, an algorithm was developed to generate a different scene order for each performance. The goal was to respect structural constraints in the script while integrating meaningful randomness and audience influence. Specifically, the challenge was to incorporate daily questionnaire responses into the structure of each night’s show, making every performance uniquely shaped by the audience.

## Features

- 📊 Real-time audience data collection through interactive forms
- 🎭 Dynamic scene ordering based on audience input
- 📱 Mobile-friendly interface

## Tech Stack
- PHP: Server-side scripting, database querying, dynamic scene generation logic
- MySQL:	Data storage for survey responses (quiz_responses) and scene orderings (scene_orders)
- HTML/CSS:	Structure and styling of the webpages, quiz, dashboard, pie chart
- JavaScript:	Interactivity for survey logic, answer collection, and dynamic user interface updates
- SVG:	Custom scalable visuals (as seen in Figure 1 – Love and Information Home Page)
